# Repository Safety

Before mutation record root, branch, HEAD, status, untracked files, submodules, worktrees, toolchain, governing instruction files, and generated-file ownership.

Never use destructive cleanup or history rewriting without explicit authorization. Do not delete unknown untracked files. Avoid unrelated mass formatting.

Dependencies require purpose, license, maintenance, version compatibility, transitive impact, and duplicate-runtime checks.

Treat generated files according to their source of truth; do not hand-edit generated output when a generator owns it.

At completion report every relevant changed, added, deleted, and remaining untracked path.
