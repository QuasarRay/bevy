# Stopping Rules

Success requires passed gates, sufficient independent verification, no unexplained diff, runtime observation when required, matching documentation, explicit limitations, and no open child.

Partial completion is acceptable when the completed subset is coherent and proven, remaining work is isolated, and repository state is safe.

Block only for objective missing access/source/permission/toolchain/hardware, overwrite risk, product-defining ambiguity, or safety restrictions. Difficulty, many files, long tests, or compile errors are not blockers by themselves.
