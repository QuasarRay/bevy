# Budget Policy

All managed agents use Max. Save budget by fewer turns and smaller contexts.

Spend on consequential uncertainty, rework-preventing architecture, accepted implementation, independent defect detection, and final proof.

Do not spend on redundant summaries, consensus agents, repeated full scans, overlapping reviewers, speculative features, or rerunning unchanged expensive suites without cause.

Use deterministic tools before an agent when the parent can interpret the result reliably.

Stop and reassess when two consecutive actions do not reduce uncertainty, the same failure recurs, stale logs dominate context, or scope grows without new acceptance gates.
