# Delegation Policy

Use the smallest role matching the missing information:

- `seqmax_explorer`: repository map;
- `seqmax_researcher`: current primary-source fact;
- `seqmax_architect`: consequential design;
- `seqmax_implementer`: approved patch;
- `seqmax_diagnostician`: reproduced unresolved failure;
- `seqmax_test_engineer`: difficult proving test design;
- `seqmax_migration_analyst`: migration inventory/order;
- `seqmax_adversarial_reviewer`: post-change defects;
- `seqmax_security_reviewer`: justified security risk;
- `seqmax_performance_reviewer`: justified measured performance risk;
- `seqmax_verifier`: final independent gates.

Each child has one primary artifact. Never invoke every role by habit. Repeat a role only after scope change, objective incompleteness, remediation, or contradictory evidence; record the reason.
