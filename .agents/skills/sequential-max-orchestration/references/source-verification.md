# External Source Verification

Research externally when facts are current, versioned, niche, high-stakes, or tied to a named external document.

Technical source order: local checked-out source, official versioned docs, upstream exact commit/tag, specification/paper, maintainer discussion, secondary source.

Record version, SHA, date, platform, and feature flags. Never apply documentation from another release because names look similar.

A research child is read-only and must return `BLOCKED` if the needed primary-source tools are unavailable.
